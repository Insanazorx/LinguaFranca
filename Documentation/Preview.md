# Former preview target

The old dummy-preview module and passages were removed at the user's request. LinguaFranca Local (and the compatibility alias LinguaFranca Preview) now use the real bundled Qwen3.5 model, language packs and replacement engine.

The com.linguafranca.app.preview identity is retained to preserve earlier user lists/settings. Startup deletes only explicitly tagged hand-authored sample readings. Previously saved vocabulary is preserved. There is no dummy generation fallback.

Use the main LinguaFranca scheme for physical-device preparation. Current tests and limits are in Verification.md and Status.md.
