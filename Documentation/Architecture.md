# Architecture

`SwiftUI → AppEnvironment → local inference actor / replacement engine / database actor`

LinguaFrancaCore owns domain models, immutable English passages with reversible UTF16 spans, settings migration, contextual processing and GRDB persistence. LinguaFrancaInference owns native llama.cpp handles, verified model loading, serialized generation, cancellation and cleanup away from the main actor. Runtime cloud inference, networking and telemetry are absent.

Balanced generation produces English only. ContextualReplacementEngine analyzes that original and queries generic LanguagePack implementations. Aggressive separately uses Qwen3.5-2B to generate paired source/mixed expressions, then checks selected occurrence coverage. Optional full-Russian reading translation also uses 2B, as explicitly authorized by the user; neither changes Balanced's generation model or replacement method. LanguagePackRegistry discovers versioned manifests and shares one bundled English POS model across targets. New languages may require morphology data or adapters.

NaturalLanguage supplies segmentation. A bundled averaged perceptron supplies POS even without optional OS English tagging assets. Native Swift predictions match fixed vectors from original NLTK 3.9.2 classes. Noun lemma candidates require actual dictionary senses, and target plurals require attested forms in SQLite. Unknown and ambiguous forms are skipped.

Sense ranking uses POS, contextual gates for high-risk polysemes, gloss keywords and ambiguity checks. Repeated words use local context; unique words can use their sentence. Hyphenated compounds are not partly translated. Subject forms are not substituted for object/reflexive pronouns merely because their lemmas match.

In Balanced, per-language frequency refers to source word tokens. Combined requests above 50% are proportionally scaled. Seeded selection first spreads words, then at high density permits pairs but never three consecutive replacements. No overlaps, destructive source changes or translation chaining occur. Actual density can be below the target and remains a diagnostic in the session reading.

Ordinary readings and replacement spans live in a non-Codable ReadingSession. Backgrounding unloads inference but preserves that value; process termination discards the session. Remix updates the same in-memory original. Migration v2 removed the old automatic archive; v5 adds a separate opt-in savedReading table holding a Codable GeneratedText snapshot and prepared translations. Save is the only route into that archive. Vocabulary examples, lists, settings, card due dates and review logs remain independent. Refresh revisions prevent stale async vocabulary/settings updates.

Inference verifies the selected GGUF against its pinned manifest before native loading. Each generation owns and releases context/sampler resources; model reuse/unload are serialized. The Qwen3.5 chat template supplies an empty thinking block. Bounded structural validation/retry cannot certify semantics or CEFR.

SRS uses the native FSRS 6 port with reference-vector tests, persistent history and scheduler-version metadata. Continuous voluntary practice prioritizes due learning/review cards, then allows balanced early repetition until the user exits. Internal progress states remain hidden from ordinary screens. Full linguistic correctness of mixed passages remains open, especially case/agreement and dependent phrases.

GenerationVocabularyPlanner selects up to three English noun hints per enabled language from topic pools, verifying that each hint has a real local dictionary equivalent that passes LexicalContrastPolicy. The prompt names the enabled languages but contains only English vocabulary, never target translations or earlier passages. International terms may occur naturally in the original prose.

LexicalContrastPolicy runs before allocation on both the resolved lemma and rendered form. Unicode folding, transliteration, spelling/suffix normalization and edit distance exclude identical and near-identical pairs across scripts. This is a conservative lookalike heuristic, not verified etymology: existing WikDict packs contain no reliable word-origin field, and some loans/cognates can escape or distinct pairs be skipped. Final sense/morphology validation still applies; density is never forced to compensate.

Every inference attempt creates and frees its own llama context and sampler; only model weights are reused. A process-local planner rotates through 576 situation/focus/perspective combinations, avoiding repeated base situations until all 12 have been used. Normalized text, opening, phrase-overlap and content-word checks reject duplicate/near-duplicate output with the existing two-attempt limit. Fingerprints are used only for post-inference validation, never as a conversation transcript. This reduces repetition but cannot prove semantic uniqueness or CEFR quality.

WritingGenre supplies six literary prompts. Dialogue, play and poem use native llama.cpp grammar sampling to enforce speaker-turn/line structure while the model generates the content. Poems have genre-specific minimum length and line-aware vocabulary context. Literary quality is still model-dependent.

ReplacementMode.aggressive supports combinations of structure, content, actions and prepositional phrases. Qwen3.5-2B proposes source-bound mixed expressions; selected occurrences are checked and missing coverage receives focused repair. Language allocation supports all enabled languages, with corpus constraints for Syriac. Frequency caps apply only to Balanced. Eligible/actual counts remain diagnostic; coverage checks cannot establish complete grammatical correctness. See Aggressive2BAndSRS.md.

SentenceSpeechController now pronounces only the tapped target expression using AVSpeechSynthesizer and an installed voice in that language. Missing voices are reported and never downloaded silently. It pauses full-text narration to avoid competing audio; full narration stops active word pronunciation.

TargetReadingTranslator preserves source sentence UTF-16 spans and obtains constrained Russian translation JSON from the existing generation protocol. ModeGenerationService unloads the other model before routing each request. AppEnvironment releases the LLM before PassageNarrator loads offline Denis synthesis and Russian word alignment. Only one sentence's audio stays in memory. The narrator maps AVAudioPlayer's real playback clock to recognized word times; the mixed view maps the source sentence through reversible replacement spans. Audio and unsaved translations are ephemeral. See RussianReading.md for assets, persistence, validation and measured limitations.

InferenceMemoryPolicy constrains large-model Metal layers and micro-batches on 4 GB iPhones, allocates context only after actual tokenization, and preserves the complete output budget. Per-chunk/native autorelease scopes bound temporary lifetimes. Large models unload after user actions; normal warnings trim optional resources while low process headroom or kernel-critical pressure interrupt safely and select a CPU fallback. Aggressive JSON prefix recovery retains complete decoded mappings before repairing missing spans. See iPhone13Memory.md for physical evidence and measurement limits.
