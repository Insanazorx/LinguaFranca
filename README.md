# LinguaFranca

Native Swift 6 / SwiftUI iOS and macOS app with local English generation, mixed-language reading and FSRS 6 flashcards. Balanced uses Qwen3.5-0.8B and the conservative replacement engine; Aggressive uses a separate Qwen3.5-2B workflow. Optional Russian reading translation also uses the 2B model. German, Russian, Arabic, Hebrew and Classical Syriac can participate together. Models, dictionaries and native dependencies are restored during the build; they are not stored in Git.

## Build from a fresh clone

Use macOS with full Xcode (Swift 6.1 or newer), its iOS and simulator SDKs, and Python 3.9+. Open Xcode once to complete Apple's installation steps. CMake 3.28+ is required for the simulator runtime; the script installs it with Homebrew if missing. Without Homebrew, install CMake before running the build.

```sh
git clone https://github.com/Insanazorx/LinguaFranca.git
cd LinguaFranca
./build.sh --test
```

This command downloads checksum-pinned dependencies, compiles the missing llama.cpp simulator slice, prepares the lexical databases and English analysis model, retrieves both mode-specific, pinned Qwen GGUF files, generates the Xcode project, runs tests, builds the simulator app, and checks the resources in the actual app bundle. Output: `build/DerivedData/Build/Products/Debug-iphonesimulator/LinguaFranca.app`. Logs and verified downloads are in `.bootstrap/`.

```sh
# Restore everything, then open the generated project in Xcode.
./build.sh --bootstrap-only
open LinguaFranca.xcodeproj

# Build for an iPhone without signing.
./build.sh --platform device

# Sign with your own Xcode account/team.
./build.sh --platform device --team-id YOUR_TEAM_ID

# Reuse the already downloaded, verified cache without network access.
./build.sh --test --offline
```

Signing and installation on a phone require your own Apple account/team and device approval. No signing credentials or personal Xcode state are committed. The app runs the model and language processing on the device; it never downloads resources at runtime.

## GitHub build

In the repository's **Actions → Build iOS app → Run workflow** screen, start the included macOS build. It restores dependencies, runs the same tests, builds the simulator app and verifies bundled offline resources. It needs no Apple signing secrets. It is manual and does not run automatically on every push. A remote workflow result is separate from the recorded local build results.

## Writing and focused practice

Choose Short story, Novel excerpt, Dialogue, Theatre scene, Essay or Poem on Generate. Novel means a short scene within the passage budget. Dialogue/play speaker turns and poem lines use native format constraints; all content is generated by the bundled local model.

Aggressive combines Sentence structure, Content words, Verbs & verb forms and Preposition + object / verb. Qwen3.5-2B writes a paired English/mixed draft; selected occurrences are checked and missing mappings repaired. Automatic allocation distributes occurrences across every selected language; category-specific language overrides are optional. Syriac targets are restricted to attested ETCBC corpus equivalents, with rebalancing when unavailable. Conjunction/preposition repairs use licensed local sense candidates where available. Balanced retains its previous model, frequency controls and conservative lexical engine. Models are released before switching, so they never remain loaded together. See [implementation and validation](Documentation/Aggressive2BAndSRS.md).

On 4 GB iPhones, the 2B runtime uses a bounded Metal allocation, smaller working batches, prompt-sized contexts and pressure-aware cleanup. Completed mappings survive truncated JSON so long passages only repair missing expressions. Physical iPhone 13 testing and measured limits: [iPhone13Memory.md](Documentation/iPhone13Memory.md).

Open a vocabulary list and select a language group. The top action writes entirely in that language using the group's words, in batches of up to three. Attested inflections count toward coverage. Texts stay only in the current app process. The small model can still make grammar mistakes; output checks verify language, structure and word coverage, not linguistic quality. See Documentation/AggressiveAndVocabularyPractice.md for validation and limitations.

Tap a mixed word, then Pronounce to hear only that expression in its target language using an installed system voice. Audio stops when the sheet closes or the app becomes inactive. Voice availability depends on the system; the app never downloads voices silently or substitutes another language for Syriac.

## Reading and vocabulary

Every registered target language has a saved frequency slider from zero to Psycho (50% target). Simultaneous languages share an overall 50% ceiling. Actual density depends on conservative lexical coverage and is displayed separately. Tap Remix to apply settings to a session reading without rerunning the model. International lookalike pairs stay in English. Target-language-aware prompts use verified local vocabulary hints and varied scenarios; previous prose never enters the model prompt. Tap a highlighted word to reveal the English original and save it with its example sentence to a list. Backgrounding retains readings; fully closing the app clears unsaved readings. Save explicitly keeps a passage and its prepared translations in the local Readings library. Vocabulary, lists and review history remain separate.

Use **Listen → Russian** above a passage to hear the entire text in Russian with the bundled Denis voice. Qwen3.5-2B translates the original English sentence by sentence, then unloads before offline speech synthesis. Switch between Mixed text and Russian; Follow spoken words marks the spoken Russian word, or the corresponding sentence in the mixed view. Word timestamps come from analysis of the actual generated audio; unmatched words may have no marker. Save keeps the translation for later practice, while audio is regenerated locally. The build restores all pinned speech assets; the installed app makes no downloads. See [Russian reading, saved texts and validation](Documentation/RussianReading.md).

Local-model generation, mixed-language reading, vocabulary/list persistence and initial iPhone 13 installation/launch are verified. CEFR is a prompt target; prose and lexical sense selection still need quality review. FSRS 6 scheduling is implemented and checked against official reference vectors. Complete target-language grammar and human-reviewed semantic quality remain ongoing work. Mac/simulator timings are not physical-device performance measurements.

See [build details](Documentation/Build.md), [project status](Documentation/Status.md), [verification](Documentation/Verification.md), [model measurements](Documentation/ModelBenchmark.md) and [data licenses](Documentation/LexicalDataLicenses.md).

## Flashcards and dictionaries

Study offers unrestricted practice: all saved words, a chosen list, individual words or the separate Forgotten words list. Practice shows only a portrait 2:3 card, randomly colored yellow, green, blue or red, with an exit control. Tap to flip and drag cards freely in two dimensions. Right/left releases rate Good/Again; vertical or short releases spring back. The chosen list repeats until you exit: due FSRS cards first, then balanced early repeats. FSRS 6 remains internal and persists history without due-date or daily gates. Progress states are hidden from normal screens.

Dictionary searches all five bundled language packs, including 346,547 senses/lexemes/roots, alternate translations and exact inflected spellings. Browse definitions, recorded forms, etymology, source links, save to study lists, and open Semitic Roots & Morphology from the same tab. The paginated FTS catalog is built offline by build.sh. See [details and checks](Documentation/DictionaryAndFreePractice.md).

## Native Mac app

```sh
./build.sh --platform mac --test
open build/DerivedData/Build/Products/Debug/LinguaFranca.app

# Subsequent builds with a complete verified cache
./build.sh --platform mac --test --offline
```

Requires macOS 14+ and full Xcode with the macOS SDK. The Mac build uses the pinned native llama.cpp framework slice and does not build or require the simulator runtime. Select **LinguaFranca Mac** in Xcode. It is a native SwiftUI/AppKit application with its own presentation sources under `Mac/`, a sidebar, resizable window, macOS Settings, and the same offline models, five dictionaries, Semitic tools, vocabulary and FSRS storage as iOS. Cmd–1 through Cmd–5 navigate the original sections; Cmd–6 opens Readings. Cards support mouse/trackpad dragging, Space to flip, Left/Right to rate, and Escape to close. Right-click words or lists to edit or remove them.

Debug builds are ad-hoc signed for local development. For a hardened Release, use `--configuration Release --team-id YOUR_APPLE_TEAM_ID` with an installed Apple Development signing identity; the app and framework must share that team. The installed personal Mac Release uses this signing route and retains App Sandbox and library validation. It is not a notarized distribution. Mac UI sources are excluded from the iOS targets. Each platform has its own local library; unsaved readings remain in memory until the app quits. See [Mac implementation and validation](Documentation/MacApp.md).

Mac and iOS use the same original book application icon. `build.sh` renders the platform icon assets locally from `Tools/prepare_mac_icon.swift`; no image download is required.

Continuous practice, scheduling details and validation: [ContinuousStudy.md](Documentation/ContinuousStudy.md).

## Additional languages and word families

Latin, Spanish and French join German, Russian, Arabic, Hebrew and Classical Syriac. Dictionary can look up an English expression across every installed language. Latin Vocab compares any native pair of Latin, Spanish and French independently of English, with separate recorded-origin and identical-spelling labels; passages can add all translated expressions to a study list without resetting cards. Data-only `.lfpack` folders can add future languages offline. See [the pack and feature guide](Documentation/ModularLanguages.md) for build/export/import instructions, coverage and limitations.

## Everyday reading and vocabulary browser

**Nichijou** sits beside B2/C1 and asks for useful everyday English, from common words to intermediate expressions. Writing genres have flexible but validated layouts, including conversational speaker turns, theatre stage directions and eight-line poems. All generation preferences are above the reading on Generate and save automatically. Vocabulary uses a searchable green word browser with a detail pane on Mac/tablet and a detail push on compact iPhones, plus multi-word selection for practice. See [validation and limitations](Documentation/EverydayReadingAndWordFamilies.md).
